# USER — Design Profile

- Пользователь предпочитает русский язык, обращение «Би», «Гума Би» или «Гумар Би» и общение на «вы».
- Пользователю нужен готовый практический результат, а не ручное программирование ради программирования.
- Технические объяснения должны учитывать начальный уровень Linux и программирования без снисходительного тона.
- Пользователь развивает практические процессы вокруг AI, автоматизации, визуального производства и AI-видеогенерации.
- В дизайн-задачах сначала показывать вывод, главную причину и ближайшее действие; неизвестные факты не додумывать.

Этот профиль намеренно не содержит бытовую, финансовую, учебную, coding или полную инженерную память основного Hermes.
