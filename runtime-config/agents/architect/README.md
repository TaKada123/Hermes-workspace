# Architect — самостоятельный агент

Запуск из любой папки: `hermes architect`. Команда `architect-direct` также сохранена.

Рабочие данные: `/home/vottak/Проекты/Hermes-workspace/agents/architect`. Это приватная папка, исключённая из Git. Здесь, в `runtime-config/agents/architect`, находятся только публичные определения и инструменты.

У агента своя сохранённая память и история, утверждённый SOUL, прежние skills, Code Graph и Context7. Обязательная передача Main/Design и AG2 отключена. Временные подагенты разрешены.

`.env` — собственный закрытый файл рабочего home. Нативный алиас `~/.hermes/profiles/direct-architect` указывает на этот home и обеспечивает штатный доступ к общему OAuth без копирования токенов. Runtime и MCP executables остаются общими установленными зависимостями.

Перенос выполнен прямым копированием с SQLite backup. Старый экспериментальный `scripts/direct_agent.py` не использовался; его инструкции установки не относятся к текущему состоянию. MCP и модель по просьбе пользователя не тестировались.
