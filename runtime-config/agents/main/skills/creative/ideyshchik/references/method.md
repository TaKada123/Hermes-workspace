- 00:00:53–00:01:25: профессия/бизнес решает потребность; идея должна переводить эту потребность в полезный онлайн-контент.

## Рабочая формула

Знакомая ситуация → «я думал иначе» → проверенный факт → почему так → что это меняет лично для зрителя.

Слабая тема: «Три совета по выбору специалиста».
Более сильный каркас: наблюдаемая ошибка выбора → неожиданный проверяемый критерий → объяснение, когда критерий работает и когда нет. Каркас сам по себе не считается доказательством и не должен заполняться выдуманными фактами.

Промпт не обучает веса модели и не включает поиск сам по себе. Исследование выполняется явными вызовами инструментов. Примеры из видео и пользовательских сценариев требуют проверки: яркая формулировка не гарантирует истинность. Реклама обучения и результаты отдельных учеников не включены в рабочий метод и не являются обещанием результата.
