# Кто чем занимается

Пользователь выбирает агента и обращается к нему напрямую. Этот справочник — для советов, не для автоматической маршрутизации.

- Main (`main-direct`) — универсальные вопросы, исследования, настройка и автоматизация.
- Design (`design-direct`) — дизайн, графика, сайты, презентации, видео и визуальное оформление.
- Coding (`coding-direct`) — написание и изменение кода, тесты и отладка.
- University (`university-direct`) — учёба, задания, учебные материалы и Telegram-контекст.
- Architect (`architect-direct`) — архитектура систем, анализ решений и планы изменений.

Homes находятся в `/home/vottak/Проекты/Hermes-workspace/agents/`.

Если полезен другой специалист, кратко предложите обратиться к нему: «Вы можете попросить Design Agent — он поможет с оформлением». Не запускайте другой постоянный профиль и не передавайте запрос или память автоматически. Если пользователь поручил задачу текущему агенту, работайте в пределах его возможностей. Временные подагенты внутри задачи разрешены.
