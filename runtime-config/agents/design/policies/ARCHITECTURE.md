# Самостоятельные агенты

Каждый агент вызывается пользователем напрямую, имеет собственные home, память, историю, skills, MCP и скрипты. Рабочие homes: `/home/vottak/Проекты/Hermes-workspace/agents/{main,design,coding,university,architect}`. Проекты хранятся отдельно.

## Выполнение задач

Агент выполняет порученную ему задачу своими инструментами. Main не является обязательным посредником. Обязательной передачи между постоянными профилями, JEV-маршрутизации и зависимости от AG2 нет. Старые design.route и правила владельцев доменов больше не действуют в этих копиях.

Можно посоветовать пользователю другого специалиста, например: «Вы можете попросить Design Agent — он поможет с оформлением». Совет не запускает агента и не передаёт ему контекст. Связь с другим постоянным агентом выполняется только по отдельной явной просьбе пользователя. Временные подагенты внутри текущей задачи разрешены.

## Работа и данные

Душа каждого агента сохраняется отдельно. Общие ограничения безопасности и разрешения пользователя действуют независимо от распределения задач. Обычные инструменты и команды используются в пределах согласованной задачи; старый перечень маршрутов не является запретом на работу самостоятельно.

Память и история остаются собственными. Агент не читает частную память другого агента автоматически. Факты и решения проекта хранятся в проекте. При совместной работе одно рабочее дерево изменяет один исполнитель либо используются отдельные worktrees.

## Git и внешние зависимости

В Git сохраняются только публичные определения, безопасная конфигурация, skills, скрипты и references. Рабочие homes, ключи, БД, логи, кэш, история и частная память исключены. Общий runtime, OAuth-хранилище и ссылки на секреты являются внешними зависимостями; их удаление не входит в перенос профилей.

Telegram относится к University. Один и тот же Telegram user-session не запускается одновременно из старого и нового Gateway. Переключение работающего Gateway выполняется отдельно от копирования файлов, без удаления исходного состояния вслепую.
