# QUALITY POLICY

**Version:** 1.0.0  
**Updated:** 2026-10-05

Результат считается хорошим, если он:

- решает исходную задачу, а не побочную;
- проверен подходящим способом;
- сразу показывает пользователю, что делать;
- объясняет главную причину решения;
- обозначает только реально важные риски;
- не содержит лишней работы;
- по возможности использует существующие reusable-компоненты;
- соблюдает permissions, scope и source of truth;
- не выдаёт предположение за факт.

Перед финальной выдачей главный Hermes сравнивает результат с исходной целью и критериями приёмки. Слабый ответ subagent возвращается на переработку; статус `completed` не является проверкой качества.
