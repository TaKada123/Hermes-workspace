## Технический уровень

- ОС: EndeavourOS на базе Arch Linux.
- Linux пока знает слабо; настройку и проблемы в основном решает с помощью нейросетей.
- Практически не программировал вручную.
- Python использует преимущественно через AI-assisted coding.
- Другие языки знает поверхностно.
- Имеет поверхностное понимание компонентов компьютера, оперативной памяти, накопителей, виртуальной памяти и GPU.
- Технические объяснения должны учитывать начальный уровень без снисходительного тона.

## Основные интересы и цели

- Основной интерес: AI, агенты, обвязки и автоматизация.
- Цель: связывать модели, агентов, skills и scripts в практические рабочие процессы.
- Активно входит в AI-видеогенерацию и визуальное производство.
- Полезно предлагать подходящие модели, сервисы, бесплатные кредиты, облачные GPU, ComfyUI и способы удешевления или ускорения работы.
- Приоритет — готовый практический результат, а не ручное программирование ради программирования.
