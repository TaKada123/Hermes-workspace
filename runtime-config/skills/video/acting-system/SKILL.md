# Acting System — Character Performance for AI Video

## Required source reference
Before applying this skill, load `references/source.md` through `skill_view(name='acting-system', file_path='references/source.md')`. This complete bundled reference is required; do not depend on Downloads.

## Scope and boundaries
This skill governs character performance only. It does not replace video prompting or Blender execution. For requested Blender artifacts, use blender-mcp for actual scene execution and translate only applicable acting/performance rules; never substitute a Seedance prompt for the Blender artifact or override requested clay/stylized treatment with photorealism. Apply to performance layer, separate from camera/look.

## Core principle
Acting is behavior under pressure, not display of emotion. A character wants something from someone, meets an obstacle, changes tactics; emotion emerges as consequence. Express inner states through observable behavior.

## Scene construction
For each visible character determine an objective (playable verb aimed at a partner), obstacle and stakes, concrete tactics that change when one fails, and usually 2–4 visible beat shifts (pause, posture, tempo, gaze, distance or action). Subtext may diverge from words. Include listening/reaction, sometimes beginning before the partner finishes, plus an assessment before consequential answers. Use motivated physical business; an interrupted action can punctuate a beat. Body, breath, status and distance reflect the moment. Pauses contain assessment, decision or refusal.

## Performance paragraph
Adapt each character's stable identity to this scene in one flowing paragraph. Include physical state, motivated behavior, triggered habits where known, mask/crack if established, and eye life: targeted gaze shifts, natural state-sensitive blinks, live catchlights, eyes leading thought/head. No wardrobe, camera or color in acting text. Do not invent biography or vocal identity absent context.

If a master profile exists, preserve its core; transform behaviors incompatible with current posture. Include only characters present. Keep exact supplied dialogue. Paste a provided locked voice prompt verbatim when applicable; omit it for silent characters.

## Video constraints
Describe action states, not long transitions. Ensemble reactions stagger rather than synchronize unless choreographed. Movement is motivated. Stillness can convey strength; threat needs no wind-up. Carry emotional/physical inertia across beats; avoid instant resets.

## Check
Verify objective, obstacle/stakes, visible beat changes, listening, plausible business, motivated distance/status, eye life, voice consistency, states-not-transitions and no invented facts. Aim for specific, observable behavior with truthful contradictions.
