# Самостоятельные агенты — текущая организация

Все рабочие homes находятся в `agents/` этого репозитория, но целиком исключены из Git. Публичные определения и инструменты хранятся отдельно в `runtime-config/agents/`.

| Агент | Прямой запуск |
| --- | --- |
| Main | `hermes` |
| Design | `hermes design` |
| Coding | `hermes coding` |
| University | `hermes university` |
| Architect | `hermes architect` |

## Правила

Для привычного синтаксиса откройте новый Bash-терминал либо выполните `source ~/.bashrc`. Пользовательский dispatcher `~/.local/bin/hermes` выбирает агента по первому аргументу; пустой выбор — Main. Команды `*-direct` оставлены для совместимости. Нативные `direct-*` алиасы — ссылки на новые homes, а не копии старых профилей.

Пользователь выбирает агента. Обязательная передача между постоянными профилями отменена. Main имеет справочник и может посоветовать специалиста, но не запускает его автоматически. Временные подагенты внутри задачи остаются разрешены. Души сохраняются; Architect использует отдельно согласованную роль.

Изменение правил выполнено в новых копиях: отключены старые routing/network plugins и design-router, заменены устаревшие локальные правила архитектуры, добавлен самостоятельный режим в `agent.system_prompt`. Для применения нужно открыть новую сессию; старый кэшированный контекст не переписывается.

## Что хранится в Git

- SOUL, безопасная конфигурация `config.public.json`, локальные skills, scripts и references.
- Локальные публичные политики и команды запуска.
- Ссылки на общие зависимости в `DEPENDENCIES.json`.

В пакет не входят USER/MEMORY, история, БД, ключи, `.env`, auth, Telegram session, логи и кэш. Конфигурация отфильтрована: credential-поля и заголовки авторизации не сохраняются; из MCP env сохраняются только явно безопасные переменные. `config.public.json` — публичное описание, а не резервная копия всех секретных настроек и не автоматический установщик.

## Внешние зависимости

Команды используют тот же установленный runtime, что и Gateway; MCP executables и часть capability symlinks остаются общими. Каждый `.env` — собственный закрытый файл агента, а не ссылка на старый профиль. Для штатного общего OAuth созданы только нативные алиасы `~/.hermes/profiles/direct-*`, указывающие на новые homes; OAuth-токены не копировались. Общие runtime, OAuth-хранилище и MCP в `~/.hermes` сохраняются. Исходные именованные профили больше не нужны для `.env` или Telegram; уже существовавшие неработающие ссылки на отсутствующие `.claude/skills` оставлены как были, без попытки ремонта.

## University / Telegram

Учебные skills, контекст, свежие сообщения, вложения и SQLite-состояние Telegram находятся у нового University. Работающий systemd Gateway переключён на `~/.hermes/profiles/direct-university`, который ссылается на `agents/university`. Старый Gateway остановлен до копирования состояния; новый подключился в режиме read-only. Параллельный второй монитор не запускался. Исходные профили пока сохранены.

## Ограничения проверки

По просьбе пользователя не выполнялись новые MCP/model tests, аудит prompt, тестовые наборы или ревью. Проверены только результаты записи, сохранность частных файлов при копировании и исключение runtime из Git. Старый экспериментальный `scripts/direct_agent.py` не является использованным способом переноса и имеет известные замечания; не использовать его для следующих агентов.
